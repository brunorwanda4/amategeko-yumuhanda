---
title: Keyboard Shortcuts
description: Desktop keyboard shortcuts (Windows/Linux). Ignored on Android.
---

Shortcuts are active only on desktop. Disable them in Settings → **Keyboard shortcuts**.
Single-key shortcuts are suppressed while a text input is focused (only Esc and Ctrl+ combos work).
`Cmd` replaces `Ctrl` on macOS.

## Global

| Shortcut | Action | Active on |
|---|---|---|
| `Ctrl+1` | Go to Home | Everywhere |
| `Ctrl+2` | Go to Quiz | Everywhere |
| `Ctrl+3` | Go to Questions | Everywhere |
| `Ctrl+4` | Go to Stats | Everywhere |
| `Ctrl+5` | Go to Settings | Everywhere |
| `Esc` | Close dialog / go back | Everywhere |
| `?` or `F1` | Open shortcut help | Everywhere |

## Home

| Shortcut | Action |
|---|---|
| `1` | Start Easy mode |
| `2` | Start Medium mode |
| `3` | Start Hard mode |
| `Enter` | Resume unfinished exam |

## Easy mode quiz

| Shortcut | Action |
|---|---|
| `A` `B` `C` `D` or `1` `2` `3` `4` | Choose answer |
| `Enter` | Next (after answering only) |
| `←` | Previous question |
| `→` | Next (after answering) or skip (unanswered) |
| `K` | Toggle star / bookmark |

## Medium mode quiz

| Shortcut | Action |
|---|---|
| `A` `B` `C` `D` or `1` `2` `3` `4` | Choose answer |
| `Enter` | Next |
| `←` / `→` | Navigate |
| `M` | Toggle flag |
| `K` | Toggle star |
| `Ctrl+Enter` | Finish (opens confirmation dialog) |

## Hard mode quiz

| Shortcut | Action |
|---|---|
| `A` `B` `C` `D` or `1` `2` `3` `4` | Choose answer |
| `Enter` | Confirm answer |

Navigation, Esc-back, and skip are disabled during a Hard exam.

## Results

| Shortcut | Action |
|---|---|
| `R` | Retry same questions |
| `W` | Retry wrong answers |
| `1` `2` `3` | Filter questions |
| `Esc` | Go to Home |

## Questions screen

| Shortcut | Action |
|---|---|
| `/` or `Ctrl+F` | Focus search box |
| `↑` / `↓` | Move through list |
| `Enter` | Open / close question |
| `K` | Toggle star |
| `H` | Hide / show answers |

## Stats screen

| Shortcut | Action |
|---|---|
| `1` `2` `3` `4` | Switch filter |

## Settings screen

| Shortcut | Action |
|---|---|
| `Ctrl+S` | Save settings |
