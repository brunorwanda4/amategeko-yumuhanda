## Home (Ahabanza)

Mode selection cards — Easy, Medium, Hard — plus a quick stats overview. Shows a **Resume** banner when an in-progress attempt exists, and a shortcut to weak-question practice.

## Quiz (Ikizamini)

The active question view. Layout varies by mode:

- **Easy:** question, four options (A–D), instant colour feedback, back/forward navigation, star button.
- **Medium:** question, options, a 20-cell jump grid, flag button, countdown timer pill, finish button.
- **Hard:** question, options, confirm button per question, segmented progress bar, countdown timer pill. No grid, no back.

## Results (Ibisubizo)

Shown after every attempt. Displays a circular score badge, pass/fail banner, and a filterable list of all questions with your answer highlighted. "Retry wrong" launches an Easy-mode session with only the missed questions.

## Questions (Ibibazo)

Searchable, filterable question bank. Search by text or question number. Filter chips: All, Has Image, Mistakes Only, Starred Only. Toggle **Hide Answers** to use flashcard mode — answers reveal on tap.

## Stats (Imibare)

Four summary tiles (total attempts, average score, high score, pass rate), a 10-attempt vertical bar chart, a mode breakdown table, overall question coverage bar, and a ranked list of most-missed questions with a practice launcher.

## Settings (Igenamiterere)

All configurable options — see [Settings](/docs/settings) for the full list.
