The web version runs directly in your browser at [/app](/app). It has the same {questionCount} questions as the downloadable apps, available in both English and Kinyarwanda.

Quiz modes, number of questions, and "Study all questions" work on the web as in the apps. Progress is saved only in this browser (lost if site data is cleared), and the web needs an internet connection on the first visit.

### Web Details

- **All questions included:** The web version contains all {questionCount} questions in English and Kinyarwanda, with road-sign images and explanations.
- **Modes & features:** Easy, Medium, and Hard quiz modes, custom number of questions, and "Study all questions" work on the web as in the apps.
- **Storage:** Progress is saved only in this browser (lost if site data is cleared).
- **Network:** An internet connection is needed on the first visit to download the application runtime and assets.
- **Updates:** No built-in update check on the web because it always opens the latest version.
- **Shortcuts:** Ctrl shortcuts are off on the web to avoid clashes with browser shortcuts.

### Supported Browsers

The web version requires hardware-accelerated graphics support:
- Chrome, Edge, and other Chromium-based browsers (desktop and mobile)
- Safari on macOS, iOS, and iPadOS (version 16.4+)
- Firefox (version 115+)

Your browser must support WebGPU or WebGL2.
