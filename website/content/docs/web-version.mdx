Amategeko y'Umuhanda can run directly in your web browser at [/app](/app).

## Comparison

| Feature | Web demo | Windows and Android |
|---|---|---|
| **Questions** | {sampleCount} sample questions | All {APP_QUESTION_COUNT} questions |
| **Quiz modes** | Easy, Medium, and Hard | Easy, Medium, and Hard |
| **Languages** | Kinyarwanda | English and Kinyarwanda |
| **Saves progress** | Saved only in this browser (lost if site data is cleared) | Saved locally on device |
| **Works offline** | Needs an internet connection | No internet required |
| **Updates** | Always opens the latest version | Built-in update check |
| **Keyboard shortcuts** | Ctrl combinations are turned off to avoid clashes with the browser | Full keyboard shortcuts (desktop) |
| **Install** | None (runs in browser) | Download and install |

## What the demo limits

- Quiz length cannot be more than {sampleCount}
- "Study all questions" covers only the samples
- Practice sets such as Signs may have fewer questions

### Supported Browsers

The web version requires hardware-accelerated graphics support:
- Chrome, Edge, and other Chromium-based browsers (desktop and mobile)
- Safari on macOS, iOS, and iPadOS (version 16.4+)
- Firefox (version 115+)

Your browser must support WebGPU or WebGL2.
