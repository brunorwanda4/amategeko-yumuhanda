Amategeko y'Umuhanda can run directly in your web browser at [/app](/app). It provides the same full quiz experience as the desktop and mobile applications without requiring any installation.

### Supported Browsers

The web version requires hardware-accelerated graphics support:
- Chrome, Edge, and other Chromium-based browsers (desktop and mobile)
- Safari on macOS, iOS, and iPadOS (version 16.4+)
- Firefox (version 115+)

Your browser must support WebGPU or WebGL2.

### Differences from the Downloaded App

- **No automatic updates**: You are always running the latest version published to the site.
- **Local browser storage**: Progress and quiz history are saved in localStorage in this browser only. Clearing site data deletes it.
- **First-load internet**: The WebAssembly bundle loads on your first visit; afterwards, assets are cached by your browser.

If you prefer completely offline practice or want cross-device file backups, [download the native app](/download) for Windows or Android.
