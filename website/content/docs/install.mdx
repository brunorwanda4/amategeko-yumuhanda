import { RELEASES_URL } from "../../lib/config";

## Android

**Requirements:** Android 8.0 or newer, ARM64 device.

1. Download `Amategeko-y-Umuhanda-vX.X.X-Android-arm64.apk` from <a href={RELEASES_URL}>GitHub Releases</a>.
2. On your device go to **Settings → Apps → Special app access → Install unknown apps** and allow your browser or file manager.
3. Open the downloaded APK and tap **Install**.

**Via ADB:**
```sh
adb install Amategeko-y-Umuhanda-vX.X.X-Android-arm64.apk
```

## Windows

**Requirements:** Windows 10 or newer (64-bit).

1. Download `Amategeko-y-Umuhanda-vX.X.X-Windows-Setup.exe` from <a href={RELEASES_URL}>GitHub Releases</a>.
2. Run the installer.
3. If Windows SmartScreen appears, click **More info** → **Run anyway**.
