| Setting | Default | Range / Options |
|---|---|---|
| **Pass mark** | 12 / 20 | 10 – 20 (step 1) |
| **Medium mode duration** | 20 min | 10 – 40 min (step 1) |
| **Hard mode duration** | 12 min | 5 – 20 min (step 1) |
| **Easy mode elapsed timer** | Off | On / Off |
| **Hard mode image weighting** | On | On / Off |
| **Keyboard shortcuts** (desktop) | On | On / Off |
| **Theme** | System | System / Light / Dark |
| **Font size** | 100% | 85% – 125% |
| **Interface language** | English | English / Kinyarwanda |
| **Question language** | English | English / Kinyarwanda |
| **Show both languages** | Off | On / Off |
| **Updates** (desktop / Android) | On | Check for updates automatically |
| **Vibration on timer warning** (Android) | Off | On / Off |

**Danger zone:** Clear all attempt history, statistics, and saved state. Requires double confirmation.

## On the web

No built-in update check on the web because it always opens the latest version. Progress is saved only in this browser (lost if site data is cleared).
